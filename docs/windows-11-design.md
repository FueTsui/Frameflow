# Windows 11 Fluent 2 界面设计

版本：0.2.1 · 2026-09-30。

界面按 Windows 11 Fluent 2 视觉语言，在现有 Rust / egui 桌面架构上实现。保留系统窗口标题栏、最小化 / 最大化 / 关闭、缩放与系统贴靠，以及原生文件选择器。应用内容由 egui 绘制；本次不是 WinUI 3 迁移，也不使用真实 Mica / Acrylic 材质。

## 导航与设置结构

左侧提供八种媒体功能，选中项使用蓝色短竖线与背景状态。顶部仅保留菜单图标，可将导航收起为图标栏，并保存折叠状态。系统标题栏保留应用名称，工作区不重复显示大标题或品牌顶栏。左侧底部「设置」打开外观、媒体引擎、更新及帮助页面。

每种功能保留「文件与任务」页签，另设对应的设置页签。设置按该功能的实际输出组织，八种导出配置分别保存，切换功能时恢复相应配置。外部字幕、音频和效果素材路径仅保留在当前会话。

| 左侧功能 | 设置页签 | 分组与布局 |
| --- | --- | --- |
| 格式转换 | 转换设置 | 输出视频；画质与尺寸；音频；字幕；画面编辑 |
| 视频压缩 | 压缩设置 | 压缩目标；输出视频；尺寸与帧率；音频；字幕；画面编辑 |
| 片段裁剪 | 裁剪设置 | 时间范围；裁剪方式；按精确或无损模式显示可用输出设置 |
| 音频处理 | 音频设置 | 时间范围；输出音频；音轨与混音 |
| 制作 GIF | GIF 设置 | 时间范围；动画参数；画面编辑；不显示固定为 GIF 的格式选择框 |
| 截取画面 | 截图设置 | 截取位置；输出图片；画面编辑 |
| 无损封装 | 封装设置 | 封装格式；音频及外部音轨；字幕及字体附件 |
| 字幕提取 | 字幕设置 | 选择字幕；字幕格式 |

## 分组与排版

- 使用中性背景、轻边框、圆角容器和蓝色强调色，统一系统、浅色和深色外观。
- 常用参数优先显示；音频、字幕、硬件等按需展开。宽窗口将标签和控件按设置行对齐，窄空间允许换行和垂直滚动。
- 压缩的画质、码率、目标体积与两遍编码仅放在「压缩目标」；转换和精确裁剪在「画质与尺寸」统一调整画质、分辨率和帧率。
- 容器、视频编码及执行设备放在「输出视频」，硬件解码、设备编号和 GPU 缩放位于其「硬件选项」。
- 视频的「音频」统一提供源音轨、音频参数与混音。音频处理的「输出音频」集中提供格式、码率 / VBR、采样率、声道和位深，源音轨与混音独立成组。
- 源字幕与外部字幕位于同一个「字幕」分组；选择字幕方式后只显示对应选项。字体附件仅在 MKV 输出时显示，烧录仅在重新编码时显示。
- 无损裁剪与封装不显示重新编码、画质、缩放、混音等无效参数。切换格式或设备时统一调整不适用的设置，面板是否展开不影响结果。
- 时间范围按开始 / 结束排列，裁剪和音频采用「时:分:秒:毫秒」，GIF 采用「秒:毫秒」；截图只显示截取位置。
- 底部固定输出文件夹、命令与日志、开始 / 取消入口，移除重复保存位置卡片与右侧说明。移除底部状态栏，引擎状态集中在设置页。
- Windows 优先使用 Segoe UI Variable / Segoe UI，中文使用 Microsoft YaHei UI；图标优先使用 Segoe Fluent Icons，缺少系统字体时回退。

字号层级与基线对齐参考 [Fluent 2 Typography](https://fluent2.microsoft.design/typography)，分组和间距参考 [Fluent 2 Layout](https://fluent2.microsoft.design/layout)。侧栏的展开、紧凑与选中状态参考 [Microsoft NavigationView](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/navigationview)。

软件与 FFmpeg 更新在宽窗口并排，窄窗口上下排列；两者各自记住自动检查开关。应用主题无补充描述，帮助链接排列在应用名称右侧。

## 无悬浮提示交互

鼠标悬浮不显示工具提示，包括图标说明、控件提示和省略文本的自动提示。图标按钮保留无障碍名称，常用动作使用可见文字；不以鼠标悬浮承载必要操作信息。

字幕、字体及效果素材的文件名可简化显示，点击「路径」展开完整路径，并提供「复制路径」。错误、格式限制和处理状态在页面直接显示。保留 `Ctrl+O` 添加文件、`Ctrl+Enter` 开始处理。
