# Windows 0.2.1 发布验收

日期：2026-09-30。目标：Windows x64，Rust GNU release 构建。版本号保持 **0.2.1**。

## 本轮变更

- 移除应用主题说明、菜单按钮文字和底部状态栏，帮助链接移到应用名称右侧。
- 软件更新位于 FFmpeg 更新右侧，窄窗口上下排列，两者分别保存自动检查开关。
- 软件从公开 GitHub 稳定版检查更新，下载后验证文件名、大小、SHA-256 和安装器格式；点击「安装并退出」才启动安装向导。媒体任务运行时不能安装。
- 安装器记住上次路径，可直接选择现有目录，支持同版本覆盖。首次安装默认 `C:\Programs\Frameflow`，软件更新默认沿用当前程序目录。
- 保留八种独立功能设置、可折叠导航、无悬浮提示、毫秒时码、CPU / GPU H.264 / H.265、音频压缩和功能检查中的全部「优先 / 次优先」功能。

内置 FFmpeg / FFprobe 9.0.2。源码、安装包与版本发布入口为 [FueTsui/Frameflow](https://github.com/FueTsui/Frameflow)。

## 构建与测试

Release 回归 **114 项通过，0 项失败，3 项忽略**；忽略项为 FFmpeg 联网更新安装、软件发布元数据和安装包联网下载核验。GNU release 构建及 Clippy 全目标严格检查通过。软件联网核验在公开发布后单独执行，结果记录在发布说明及本地 QA 日志。

本轮新增软件更新的版本比较、发布资产匹配、下载重定向约束、损坏和不完整下载清理、安装前复核、状态恢复和任务互锁测试。界面回归覆盖新布局、两个更新开关的独立持久化、帮助链接位置和无底部状态栏。

真实引擎测试覆盖 CPU / 本机 RTX 3060 的 H.264 / H.265，CUDA 解码和指定设备 GPU 缩放，九种音频格式与毫秒音频裁剪，两遍编码和取消清理，无损裁剪编码包比对，轨道元数据，四种字幕提取、烧录及字体附件，以及旋转、水印、合成、混音和 GIF / 截图。

本轮日志位于 `tools/qa-0.2.1-release`，不进入分发包。

## 界面验收

最终构建完成 37 个原生截图：八种功能 × 浅色 / 深色 × 1240×820 / 960×660 共 32 个视图，另含折叠菜单、任务页、宽 / 窄设置和公开设置图。截图采用独立测试素材；公开设置截图隐藏本地安装目录。入口见 [Fluent 2 设计说明](windows-11-design.md)。

长页面使用纵向滚动；底部操作与侧栏保持可达。截图与自动交互回归不等同于逐项人工操作全部功能。

## 覆盖安装

使用独立 AppId 和临时目录进行真实安装 / 覆盖 / 卸载，共八项检查通过：选择现有目录、记住上次路径、替换同版本程序和旧文档、Restart Manager 关闭占用文件的测试进程、显式目录覆盖历史路径、保留非程序文件、清除测试卸载注册，以及正式安装与用户设置不变。

正式安装目录、偏好与快捷方式等 56 个文件的前后哈希一致。该测试验证安装器逻辑，使用隔离的旧版载荷和占用文件测试程序；没有在用户正式目录升级，也未验证真实 Frameflow 未保存任务的关机回调。

## 分发包

安装包、便携 ZIP、源码 ZIP 及各自 SHA-256 已生成。ZIP CRC、源码逐文件一致性、程序 x64 GUI 架构、图标、窗口清单及内置引擎哈希核验通过。源码 ZIP 仅含应用源码和文档。

便携包在独立 PATH、工作目录和应用数据目录下启动，正确识别包内 FFmpeg / FFprobe，并完成 H.264 / AAC、320×180、0.5 秒转码及 FFprobe 检查。正式程序和用户偏好哈希未改变。验收文档更新后重新打包，并核对最终程序与引擎仍为已执行验证的相同文件。

最终分发目录保留三类成品及其校验文件；本轮临时构建、便携测试和隔离安装目录核验后回收，源码、内置引擎和 QA 证据保留。

## 验证边界

Intel / AMD 参数与设备绑定经过测试，但本机没有对应可用硬件，未完成其硬件导出验收。GPU 滤镜当前提供 NVIDIA 缩放，旋转、水印、合成及字幕烧录仍使用软件处理。编码器探测成功不保证全部输入编码或尺寸可用；失败显示原因，不静默改用 CPU。

目标体积是估算值；两遍编码仅用于 CPU 的目标码率 / 体积模式。毫秒是输入精度，视频和 GIF 仍受帧边界限制，无损裁剪另受关键帧限制。

本机未验证 ARM64 或 macOS 运行。应用内容由 egui 绘制，保留 Windows 系统标题栏和原生文件选择器；采用 Fluent 2 视觉语言，并非 WinUI 3 控件迁移，也没有真实 Mica / Acrylic 材质。

程序未配置 Authenticode 签名。引擎来源、许可和哈希由包内 `BUILD_INFO.json` 与 [内置引擎说明](ffmpeg-bundle.md) 记录；对应源码范围在该说明中单独列出。
