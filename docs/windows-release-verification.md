# Windows 0.2.2 发布验收

日期：2026-10-01。目标：Windows x64，Rust GNU release 构建。

## 本轮变更

- 应用主题改为同一行右侧对齐的下拉选择，支持跟随系统、浅色和深色。
- 软件更新标题右侧显示当前版本、版本发布页及 GitHub 项目链接，更新状态保留在正文。
- 使用文档和 FFmpeg 下载页面移到 FFmpeg 更新标题右侧，删除重复的应用名称、版本与空余帮助卡片。
- 宽窗口两张更新卡片根据本帧内容自动等高；内容变长时扩展、恢复后收缩，窄窗口自然上下排列。

保留八种功能、无悬浮提示、独立工作流配置、毫秒时码和软件/引擎更新。内置 FFmpeg / FFprobe 9.0.2；默认安装路径继续为 `C:\Programs\Frameflow`，覆盖安装行为沿用 0.2.1。

## 验证范围

本轮验证主题下拉交互、跟随系统、设置持久化、标题链接位置、卡片等高与伸缩、窄窗口可达性。媒体后端继续运行真实引擎回归，包含 CPU / 本机 NVIDIA 的 H.264 / H.265、音频、字幕、滤镜与取消清理。

- Release 测试：115 项通过，3 项显式联网测试默认忽略；本机 CPU 与 NVIDIA H.264 / H.265 媒体回归通过。
- `cargo fmt --check` 与严格 Clippy（全部目标、警告视为错误）通过，Windows GNU release 构建完成。

- 8 张原生设置页截图已逐张检查：1240 × 820 / 960 × 660 逻辑尺寸、浅色 / 深色、展开 / 折叠菜单，未见遮挡；可用宽度不足时改为单列并滚动。
- 便携包在隔离目录启动，实际识别包内 FFmpeg / FFprobe 9.0.2；生成并转码 0.5 秒素材，探测结果为 320 × 180 H.264 / AAC。现有安装和用户偏好哈希保持不变。

详细机器记录位于 `tools/qa-0.2.2`，不进入发布包。

## 升级与发布

发布版本为 0.2.2，现有 0.2.1 可以通过设置检查到新版本。软件下载经 SHA-256 和安装器格式校验后，点击「安装并退出」才启动安装向导；任务进行中不能安装。不会自动升级用户现有安装。

发布资产包括 Windows x64 安装包、便携 ZIP、Frameflow 源码 ZIP 和各自的 SHA-256。历史发布 v0.2.1 标签保留；本地分发目录在新包验收后清理旧产物。

## 验证边界

本轮只调整设置页和版本，不重做已验证的安装器逻辑；0.2.1 的隔离覆盖安装验收见该版本的文档。公开发布后的检查/下载不等于在用户正式安装目录执行升级。

Intel / AMD GPU 尚无本机硬件实测；GPU 缩放提供 NVIDIA 路径，字幕烧录、旋转和水印等仍使用软件滤镜。毫秒为输入精度，视频受帧边界限制，无损裁剪受关键帧限制。

应用内容由 egui 绘制，采用 Fluent 2 视觉语言，保留系统标题栏和原生文件选择器；未迁移为 WinUI 3。程序未配置 Authenticode 签名。引擎来源、许可与对应源码范围见 [内置引擎说明](ffmpeg-bundle.md)。
